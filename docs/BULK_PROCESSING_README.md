## 🛠️ **TROUBLESHOOTING**

### **No Leads Found**
- ✅ Check internet connection
- ✅ Verify keywords are not too specific
- ✅ Check rate limit settings
- ✅ Run `python3 app.py doctor`
- ✅ Try with `--limit 10` to test

### **Slow Performance**
- ⚠️ Reduce concurrent requests (max_workers in BulkProcessor)
- ⚠️ Increase delay between requests (RATE_LIMIT_DELAY)
- ⚠️ Run during off-peak hours
- ⚠️ Use faster servers
- ⚠️ Check if premium APIs are configured

### **Rate Limit Errors**
- ⚠️ Wait for daily limit to reset
- ⚠️ Reduce limit_per_source
- ⚠️ Increase RATE_LIMIT_DELAY
- ⚠️ Add premium API keys for better limits

### **Missing Data**
- ⚠️ Add premium API keys (Clearbit, Hunter.io, etc.)
- ⚠️ Check robots.txt compliance
- ⚠️ Verify website accessibility
- ⚠️ Run enrichment again

### **Database Errors**
- ⚠️ Check file permissions on leads.db
- ⚠️ Ensure databases exist (run `python3 app.py doctor`)
- ⚠️ Check disk space
- ⚠️ Verify SQLite version

### **Memory Errors**
- ⚠️ Reduce batch_size in BulkProcessor
- ⚠️ Process smaller batches
- ⚠️ Use async mode for large operations
- ⚠️ Upgrade server memory
